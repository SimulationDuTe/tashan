# iteration-7：拷问能力 × 无提示基线

日期：2026-11-21

## 问题

iteration-6 的对照（等长通用提示）内容与 skill 高度重合，只能测包装。本轮回到最直接的问题：**同一批两轮对话，有 skill 的答复比模型默认行为强吗？**

## 设计

- 题：`evals/tasks-core.json` 的 interrogation 组 3 题（q1-decompose、q2-staffing、q3-slo），两轮。
- 臂：
  - with_skill：直接复用 iteration-6 的 with_skill 两轮答复（同一个模型、同一份 SKILL.md）。
  - baseline：新生成 6 次，只给题面，无任何提示、无技能、无思考要求；第二轮同样只给它自己的第一轮答复和用户追问。
- 盲评：随机 A/B（`judgment/map.json`），两个裁判顺序对调；六维各 0–3（D1 问题界定、D2 假设与前提、D3 方案-约束匹配、D4 验证/判据、D5 表达、interrogation）。总分 18。
- 复现：`python evals/make_twoturn_packet.py iteration-7 q1-decompose,q2-staffing,q3-slo with_skill baseline`；`python evals/analyze_twoturn.py iteration-7`。

## 结果

| 题 | 判定（J1 / J2） | with_skill 六维 | baseline 六维 |
|---|---|---|---|
| q1-decompose | with / with | 18, 16 | 17, 15 |
| q2-staffing | with / with | 18, 17 | 17, 16 |
| q3-slo | with / with | 18, 18 | 17, 17 |
| 合计 | **6 胜 0 负** | 17.50 | 16.50 |

五维（不含 interrogation）均分 14.667 vs 14.000；六维 17.50 vs 16.50。两位裁判在 3 题上完全一致。

篇幅（字节，第一轮 / 第二轮）：with_skill q1 6,762/7,421、q2 3,804/5,460、q3 7,076/5,797；baseline q1 5,775/5,125、q2 5,006/6,329、q3 7,292/11,851。

## 差在哪

- **q1**：baseline 第一轮就给 12 个月的微服务分期计划（Phase 0 依赖图 → Phase 1 边缘能力 → Phase 2 目录/库存 → 服务上限 8–10），虽然在开头质疑了「微服务是趋势」，但决定性未知（痛点是发布耦合还是扩容）是在第二轮才补上的；with_skill 第一轮就把「真实痛点是上线慢还是大促扛不住」写成分支，并给「若是后者，先缓存/读写分离/压测，拆分后移」。两位裁判都因此把 interrogation 判高一分，D1–D5 基本持平。
- **q2**：baseline 同样识别出「班型错配」和跨夜空转，验证方法（20–23 首次响应直方图）也很具体；但它第二轮的人员表 5+5+3+1+1 只有 15 人，且分档改用「日均会话量」，与第一轮自己说的「日均掩盖峰值」矛盾。with_skill 的「峰值小时单量 × 0.25」换算与 18/23/31/40 分档前后一致，D3 高一档。
- **q3**：baseline 内容覆盖面更广（错误/超时计入、样本量门槛、缓存全失效演练），但它的 100ms 预算表各项相加为 120ms 且与「服务端口径」矛盾；with_skill 用「180→100 是 1.8 倍、400→100 是 4 倍」分档，预算按每跳 (75×0.8)/N 切，表内自洽，D3 高一档。

## 裁决

- 在这 3 道两轮拷问题、这套 rubric 下，**skill 相对无提示基线 6:0**，主要差在两点：第一轮先问出决定性未知（interrogation），以及内部算术/口径自洽（D2/D3）。
- baseline 不弱：它会质疑前提、会给公式、会做验证设计。skill 的优势不是「会分析」，而是「先把会改变结论的未知摆到方案前面」+「少犯自相矛盾」。
- **重要保留**：rubric 是 iteration-1 时按 skill 的原则写的（D1/D2 明确奖励「先界定未知再下结论」），所以这个 6:0 是**上界**，不是无偏效应量；n=3、同族裁判、每格 1 次生成。
- 与 iteration-6 合起来读：内容（未知量标注、可证伪、答完即停）赢过无提示基线；把这些内容换个排版不改变分数。也就是说，值钱的是内容清单，不是六步结构本身——至少在这 3 题上如此。

## 局限

- with_skill 臂复用 iteration-6 的答复，baseline 是新生成的；生成时间不同，不能完全排除模型状态差异（同一模型、同一会话族，影响应该很小，但未做交叉重跑）。
- rubric 有 skill 偏向（见上）；且裁判只看文本，不核对真实数据，算术错误靠手算抽查。
- 3 题都是「用户已给方案、需要先纠偏」的拷问题，没有覆盖「用户不给追问」「长文档」「代码」等形态。
