# 盲评提示词

用法：每题把两份答复复制进一个**新会话**，随机标成「甲」「乙」，用下面的提示词。同一题再跑一次，把甲乙对调。把两次输出都留着，交回时附上「甲/乙 对应 A/B」的映射表。

---

## 提示词（整段复制）

```
你是一名独立评审。下面是一道题和两份答复，标为「甲」「乙」。你不知道它们由哪个系统生成，不要根据篇幅、格式或语气猜来源。

题目：
<粘贴题面>

【甲】
<粘贴第一份答复>

【乙】
<粘贴第二份答复>

请按五个维度各打 0–3 分（0 最差，3 最好）：

D1 问题界定：是否说清要决定什么、难点在哪、哪些是已知/未知；0 = 答非所问或把假设当结论；3 = 界定准确并据此调整了结构。
D2 假设与前提：0 = 无假设意识；1 = 泛泛说"可能需要确认"；2 = 列出关键假设并标明不确定性；3 = 逐条说明假设失效的后果，必要时先验证再下结论。
D3 方案-约束匹配：0 = 通用清单；1 = 部分适用；2 = 与给定资源/约束匹配；3 = 方案随约束变化，给出取舍和"不做什么"。
D4 验证/判据：0 = 无；1 = 只说"要测试"；2 = 可观测指标或能证伪的实验；3 = 指标 + 预期方向 + 失败后的下一步。
D5 表达与可行动性：0 = 冗长不可行；1 = 可读但重点不明；2 = 结论清楚可执行；3 = 结论先行、篇幅匹配、可直接照做。

另外两个判断，各标「有 / 部分 / 无」：
Q1 是否在给出方案之前，点出了会改变结论的未知。
Q2 是否给出了能证伪结论的测试，或提前停手的条件。

输出格式：
1. 先给 winner：甲 / 乙 / 平。
2. 再给表格：维度 | 甲 | 乙，以及 Q1、Q2 的判断。
3. 最后各用 2–3 句话说明胜者赢在哪、输者差在哪，必须引用答复里的具体句子或数字，不要只写"更全面"。
```
