# 豆包工作版测试包：整个 skill vs 裸模型

目的：在同一个模型上，比较「加载 Tashan」与「什么都不加」对复杂问题的答复质量。你负责跑和收集，我负责盲评统计。

成本：4 题 × 2 臂 = 8 次生成，外加 2 轮盲评（可复用同一个豆包会话）。建议至少跑 T1、T2、T3 三题。

## 公平性规则（比跑分更重要）

1. **同一模型、同一版本、同一账号**，全程不要切换。开始前记下豆包界面上显示的模型名。
2. **每题独立新会话**，A 臂和 B 臂不能在同一会话里连着问。
3. **B 臂看不到 SKILL.md**，也看不到 A 臂的答案；B 臂的题面里不能出现「按某个方法」「认真分析」「深入思考」之类提示。
4. **两臂都不追加追问**。第一轮生成完就复制，不要让它「再展开一点」。
5. 记录**原始字符数**（复制到记事本看字数即可），以及它是否在回答前反问了用户。
6. 排序、评分由盲评完成，你自己不要先给结论。

## 跑法

### A 臂（有 skill）

推荐：新建一个豆包智能体，把 `SKILL.md` 的正文（从 `# Tashan` 到文件末尾，去掉开头的 YAML frontmatter）粘进「人设/指令」框，开场白留空，保存。以后每题开一个新会话跟这个智能体聊，只发题面。

不想建智能体的话，用单条消息版：

```
你将严格按下面这份「Tashan」思考技能工作。它不提供领域知识，只规定思考顺序；能一两句答完的问题就一两句答完，不展示过程。

<把 SKILL.md 正文粘贴到这里>

---

用户问题：
<把题面粘贴到这里>
```

### B 臂（裸模型）

普通新会话，只发题面。不加任何前缀、不选任何智能体。

### 记录

每跑完一次，把答复全文存成一个文件（或在聊天里贴回来），文件名：

```
runs/<题号>-A.md     # 有 skill
runs/<题号>-B.md     # 裸模型
```

每题记一行：

| 题号 | 臂 | 字符数 | 是否反问 | 备注 |
|---|---|---|---|---|
| T1 | A | | | |
| T1 | B | | | |
| … | | | | |

## 盲评

1. 每题把 A、B 两份答复复制进同一个新会话，随机标成「甲」「乙」，**自己记下映射**（写在纸上或另一个文件，别让裁判看到）。
2. 用 [judge.md](judge.md) 里的提示词，让一个**新会话**（最好换个人）打分；同一题再跑一次，把甲乙顺序对调。
3. 两轮结果一起给我。如果豆包当裁判太贵，至少跑 T1、T2 两题的盲评。

## 交回什么

- `runs/` 下 8 个答复文件（或直接把全文贴回聊天）；
- 记录表；
- 盲评两轮的原始输出；
- 豆包界面上显示的模型名和版本。

## 题在哪

见 [tasks.md](tasks.md)。每题有「题面」和「考点」两段，**只把题面发给模型**，考点是给你看的。
